Product Name

VPNWatch – Palo Alto S2S VPN Monitor

1. Objective

Build a lightweight web application on Replit that fetches, visualizes, and monitors Site-to-Site IPsec VPN status from Palo Alto firewalls using API keys, enabling real-time visibility and operational readiness.

2. Problem Statement

Network teams lack a simple, centralized view of Palo Alto S2S VPN health without logging into each firewall. Existing tools are heavyweight or expensive. A fast, API-driven dashboard is required for operations, audits, and incident response.

3. Target Users

Network Operations (L2/L3)

Security Operations

MSP / NOC teams

Architects validating VPN health during changes

ServiceNow / ITOM teams
